Reference

Guide

What the catalog fields and filters mean.

Search

Search matches any part of a title. Included genres must all appear; excluded genres are removed from results. You can combine both filters with a title.

Score

The project’s dataset records an average user score out of 10. Rankings sort entries with a score from highest to lowest.

Popularity

A rank from the original dataset. A smaller number indicates a more popular entry in that snapshot.

Format & source

Format describes whether an entry is a TV series, movie, OVA, or another release type. Source describes its original material, such as manga or a novel.

Content rating

The catalog includes age guidance from the original data. Random picks skip entries tagged with adult-oriented genres, as the original project intended.

The project

About NextEpisode

NextEpisode began as a CS257 software design team project. This hosted edition makes its anime discovery features available without the original local database.

What you can do

Search by title, include or exclude genres, browse rankings, open a detailed entry, and get a random recommendation.

The catalog is a snapshot from the team repository. It does not update live with MyAnimeList.

The team

Christian Park, Raaid Iqbal, Omar Sobhy, and Matthew Hall built the original project together.
